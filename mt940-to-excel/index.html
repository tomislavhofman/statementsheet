    What does an MT940 file look like?

    An MT940 statement is plain text made of tagged fields:

    TagContent
    :20:Statement reference
    :25:Account (IBAN, or bank code/account number)
    :28C:Statement number
    :60F:Opening balance: C/D, date, currency, amount
    :61:Statement line: value date, booking date, C/D, amount, type, references
    :86:Details of the line above: counterparty, IBAN, purpose
    :62F:Closing balance

    Amounts use a decimal comma and the sign is a letter (C for credit, D for debit), which is why the file is hard to use directly in a spreadsheet.

    Field 86 dialects

    Banks fill field 86 differently. StatementSheet reads the common ones:

    • German structured format (Sparkasse, Volksbank, Deutsche Bank and others): a three-digit business code followed by ?20–?29 purpose lines with SEPA keys such as EREF+, MREF+, CRED+ and SVWZ+, ?31 IBAN and ?32/?33 name.
    • Key/value format (Rabobank, ING, ABN AMRO): /NAME/, /IBAN/, /REMI/, /EREF/, /CNTP/.
    • Free text: kept as the description.

    How to convert MT940 to Excel

    1. Export the statement from online banking as MT940 (sometimes labelled STA, SWIFT or MT940/MT942).
    2. Drop the file above. Files with several statements or accounts are split automatically.
    3. Download Excel or CSV. Debits are negative numbers; the Statements sheet shows opening and closing balances with a check that they add up.

    If your bank offers camt.053 as well, prefer it: the XML format carries the counterparty and remittance information in separate, unambiguous fields. See camt.053 to Excel.

    Questions

    Which file extensions work?

    .sta, .940, .mt940, .txt and .dat files containing MT940 or MT942 text, and ZIP archives of them.

    What about umlauts and special characters?

    MT940 files from German banks are often in ISO-8859-1. The tool detects this and shows ä, ö, ü and ß correctly.

    Are MT942 intraday files supported?

    Yes. They are read the same way; entries marked as expected are shown as pending.

    Is my data uploaded?

    No. The file is read in your browser and never leaves your device.
